# Sporta Mobile User App

Phân hệ ứng dụng di động native dành cho người chơi thể thao, hỗ trợ các chức năng: tìm sân, xem bản đồ, tạo câu lạc bộ và thực hiện giao dịch thanh toán.

## 1. Công Nghệ Sử Dụng

* **Nền tảng:** React Native
* **Công cụ phát triển (Toolkit):** Expo
* **Ngôn ngữ:** TypeScript

## 2. Hướng Dẫn Vận Hành

Cài đặt thư viện (Chỉ thực hiện lần đầu):
`npm install`

Khởi chạy máy chủ nội bộ Expo:
`npx expo start`

## 3. Quy Trình Kiểm Thử

Để kiểm tra trực quan ứng dụng trong quá trình lập trình:
* Tải ứng dụng `Expo Go` từ cửa hàng ứng dụng (App Store / Google Play) trên thiết bị di động cá nhân.
* Quét mã QR hiển thị trên Terminal máy tính bằng thiết bị di động.
* Mọi thay đổi mã nguồn sẽ được tự động làm mới (Hot-Reload) trên thiết bị.
* Lưu ý: Thiết bị di động và máy tính phải được kết nối chung một mạng nội bộ (Wi-Fi).
